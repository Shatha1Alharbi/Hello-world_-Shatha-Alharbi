# Learning Streak Tracker

## App Name & Purpose

**Learning Streak Tracker** is an iOS application designed to help users build consistent learning habits by setting personal learning goals and tracking their daily progress.

The app encourages consistency while offering flexibility through daily activity tracking, Freeze days, and goal progress monitoring.

## Main Features

| Feature | Description |
|---|---|
| **Learning Goal Management** | Create and edit learning goals with weekly, monthly, or yearly durations. |
| **Daily Activity Tracking** | Mark each day as Learned or Frozen to track learning consistency. |
| **32-Hour Grace Period** | Record or update the previous day's activity until 8:00 AM the following morning. |
| **Flexible Status Updates** | Switch between Learned and Freeze within the allowed time window without creating duplicate daily records. |
| **Freeze Management** | Use a limited number of Freeze days depending on the selected goal duration. |
| **Interactive Weekly Calendar** | View daily progress through color-coded indicators and select eligible dates. |
| **Progress Statistics** | Track the total number of Learned and Freeze days. |
| **Goal Completion Tracking** | Automatically display whether a learning goal has been completed or not achieved. |
